# todo-list
# 할 일 관리 웹 애플리케이션

1주차에 제작한 파이썬 콘솔 기반의 할 일 관리 프로그램을 기반으로, 생성형 AI(바이브 코딩)를 활용해 PC와 스마트폰 웹브라우저에서 사용할 수 있도록 구현 및 배포한 웹 애플리케이션입니다.

# 웹사이트 접속 주소
**배포 URL**: https://namg68282-droid.github.io/todo-list/

##  주요 기능
- **할 일 추가**: 입력창에 할 일을 작성하고 추가 버튼 또는 Enter 키로 목록에 등록합니다.
- **완료 체크 및 삭제**: 항목을 클릭해 완료(취소선) 상태로 변경하거나 삭제 버튼으로 제거합니다.
- **상태 요약 대시보드**: 상단에서 전체, 남은 할 일, 완료된 항목 수를 실시간으로 확인합니다.
- **상태별 필터링**: 전체 / 진행 중 / 완료됨 탭으로 원하는 항목만 모아볼 수 있습니다.
- **자동 저장(LocalStorage)**: 브라우저를 닫았다가 다시 열어도 작성한 목록이 유지됩니다.

##  사용 방법
1. 상단 입력창에 오늘 해야 할 일을 입력한 뒤 **추가** 버튼을 누릅니다.
2. 끝마친 일은 체크박스를 눌러 완료 표시를 합니다.
3. 필요 없는 항목은 우측 **삭제** 버튼이나 **완료 항목 삭제** 버튼으로 정리합니다.

##  사용 기술
- **Frontend**: HTML5, CSS3, JavaScript
- **Hosting**: GitHub Pages
